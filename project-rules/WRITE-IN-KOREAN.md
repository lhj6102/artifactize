# 한국어 글쓰기 체크리스트

- **K-NATURAL**: 번역한 티가 나지 않도록 한국 개발자가 처음부터 한국어로 쓴 글처럼
  씁니다. 문법이 맞더라도 번역한 티가 나는 문장은 위반입니다. 영어 어순, 소유 표현
  ('…의 것', '…자신의'), 사동·피동 표현을 그대로 옮기지 않습니다. 영어로 다시 옮겨
  봐야 뜻을 알 수 있는 문장은 쓰지 않습니다.
- **K-SHORT-BREATH**: 관계절이나 분사구문이 겹친 긴 영어 문장은 한국어 두세 문장으로
  나눠 씁니다. 한 문장에 조건 표현('…하면', '…할 때')을 여러 번 겹쳐 쓰지 않습니다.
- **K-IDIOM**: 영어 동사나 비유를 사전에 나온 뜻 그대로 옮기지 않습니다. 같은 뜻을 전하는
  자연스러운 한국어 비유나 의역이 있으면 그쪽을 씁니다. 주어가 생물이 아니면 자라다,
  살다, 살아남다, 기다리다, 기억하다, 소유하다, 받아들이다, 믿다, 양보하다 같은 동사를
  직역하지 않습니다. 예를 들어 '프로젝트가 자랍니다' 대신 '프로젝트 규모가 커집니다',
  '승인이 기다립니다' 대신 '승인할 요청이 남아 있습니다', '프로그램이 살아남습니다' 대신
  '프로그램이 계속 실행됩니다'라고 씁니다.
- **K-EVERYDAY-WORDS**: 영어 단어를 글자 그대로 옮긴 말 대신 개발자가 평소에 쓰는 말을
  씁니다. 예를 들어 plain은 '평범한'이 아니라 '일반', receipt는 '영수증'이 아니라
  '실행 기록'입니다.
- **K-TERMS**: 한 개념에는 처음부터 끝까지 한 용어만 씁니다. 앱, 명령, 선언에 나오는
  제품 용어(Artifact, eval, Run, Run ID, fingerprint, GREEN, RED, 화면과 버튼 이름)는
  영어 표기를 어디서나 그대로 씁니다.
- **K-REGISTER**: 본문은 '합니다', '하세요'로 끝나는 존댓말 하나로 통일합니다.
