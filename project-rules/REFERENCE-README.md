# Reference README: ego-lite

The README we model ours on is [ego-lite's](https://github.com/citrolabs/ego-lite/tree/main)
(read on 2026-11-05). This is how it is built, not its text.

## Order

1. **Header**: a banner, a one-line tagline, badges, and a language switcher.
2. **Introduction**: two short paragraphs. The first says what the product does for the
   reader; the second says how it differs from the tools they already know.
3. **Demo**: its own section right after the introduction, holding one video of the real
   product and nothing else.
4. **Quick Start**, in numbered steps:
   1. **Install**, offered as alternatives to pick from ("pick whichever fits your flow"):
      download the app; add only the agent skill with one command; or paste a prompt that
      lets your coding agent set it up. The app also installs its skill into the coding
      agents on the machine.
   2. **Try your first task**: one slash-command example in a code block, then one short
      paragraph on what the agent does with it and what the reader gets back.
5. **Highlights**: a two-column table, a feature and what it does.
6. **The rest**, each short: a comparison with existing products, benchmarks, Docs,
   Community, Star History and License.

## Style

- It addresses the reader as "you" and leads with what they can do, before how it works.
- Paragraphs are short; tables and code blocks carry most of the detail.
- The skill connection is shown in use: how the reader adds it, then the command they type.
- Download links are badges at the top and appear again in Install.
