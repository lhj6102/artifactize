# README checklist

- **W-README-BADGES**: Place the badges at the top.
- **W-README-HOOK-VIDEO**: Follow the badges with the core hook and the introduction video.
- **W-README-EXPLANATION**: Follow the video with a short explanation of the project.
- **W-README-GET-STARTED**: Lead from that explanation into getting started through the
  installation guide.
- **W-README-INSTALL**: Installation, updating and uninstalling have one source of truth:
  the documentation's installation page. Link there instead of repeating its steps.
- **W-README-RUNNING-SCREENS**: Finish with real screenshots of the product running,
  not mockups of a screen.
