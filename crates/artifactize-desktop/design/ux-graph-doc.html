How one screen leads to another

The relations between the design's screens, as a document to read together. Every transition of the app is an edge of UX-GRAPH.md (the rules the end-to-end tests cite by id); this page places each edge between the screens it leaves and reaches, so the screens' pages can be read in the order a person meets them. The journeys a person takes are in UX-FEATURES.md; each is a path through these edges.

Screens

  • monitor · MonitorThe one screen with a Run shown: the bar, the Pane and the Main area with the Run graph. The window's and the Pane's edges start here.
  • current · CurrentThe Main area as a branch's Current: the scan header, the Current graph and the structure text.
  • detail · DetailThe inspector docked over a Run's or a Current's graph: an Artifact's tab, an eval's Summary or log, a Human eval's review.
  • review · ReviewA Human review in the Main area, and a request opened by ID shown read-only.
  • settings · SettingsThe modal with Providers, Remote and Limits.
  • overlays · OverlaysThe palette, Help, Open by ID, the Leave and Update dialogs, and the graph's find field.
  • startThe app starting, with or without arguments.
  • anyWhatever view is shown: an edge from any leaves every screen; an edge to any ends where its own To says, which is the view below a closed overlay, the same view changed in place (a refresh, a release notice), or the target the chosen palette command reaches.
  • quitThe window closed.

The map

The screens and the families of edges between them; the tables below name every edge. A Run's and a Current's graphs share the Detail, and a Human review is the same component in the Main area (Review) and on a Human eval's tab of a Run's Detail. Edges that only update the Pane in place (E-BRANCH-RUNNING, E-BRANCH-RUN-END, E-WAITING-CHANGE, E-PANE-WORKTREES) keep whatever the Main area shows and are not drawn as arrows.

Edges from any (Settings, the palette, Help, Open by ID, Refresh, quit) leave every screen, and the Pane's and the Search's edges leave the monitor, the current and the review alike (a review in the Main area stays while the Pane is used, until an entry is chosen); the map draws each once, from the monitor, for reading.

Every edge, by screen

Each row is one edge of UX-GRAPH.md, with the screens it leaves and reaches (monitor current when a Run's and a Current's graphs share it; review detail when the Human review is in the Main area or on a Human eval's tab). The From, Action and To columns are the rule's own words.
