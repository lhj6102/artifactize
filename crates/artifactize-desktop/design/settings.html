Settings: a modal over the screen

Ctrl+, or the bar's Settings button opens Settings over the screen; Esc, Close or the button again closes it with the screen beneath as it was. Three tabs: Providers (a list beside the chosen provider's setup), Remote (the shared review store) and Limits (the sign-off idle grace).

Rules

D-SET-1
Settings is a --surface-raised dialog with a 1px --line-panel border and --radius-chip corners over a --scrim, at most 900px wide and the window's height less 80px, 12–16px padding; the bar stays above the scrim. Its header row holds the title at --text-title semibold, the tabs, and Close with its Esc key cap at the end; one --ink-2 line under it says these are the CLI's settings. a full-screen page; a 20px radius.
D-SET-2
The tabs are text: --ink-2, the active one --ink semibold with a 2px --accent line below; they are a tab list (←, → move, the active one focusable). pill tabs; the active tab filled.
D-SET-3
Providers is two columns: a 180px list of --row rows (built-in providers in their order, custom providers by name, + Custom provider last), the current one on --selection and semibold; the chosen provider's setup at the right in sections separated by --line-group, each under a section header row of the inspector's anatomy without the fold icon (D-INS-9: --row high, the name at --text-small semibold), then a --ink-2 description, facts as a key/value grid (keys in --ink-2) and actions as 24px buttons in one row; a key field is a --surface-input field and never shows a value. cards per provider; a password field pre-filled.
D-SET-4
Remote and Limits use the same section anatomy: fields on --surface-input in a labelled grid, one row of buttons, and the status or result as one line in its tone (--green done, --yellow warning, --red failed). a status in a coloured box.
D-SET-5
A provider's setup states its account as a fact of the grid: Codex signed in or out; Claude Agent as Claude Code reports it (claude not found, not signed in, signed in with its login method and plan, or the error it failed with) with Check again beside it; an API-key provider's key as set from the environment (naming the variable), saved here, or not set, never its value. Its actions are one row of 24px buttons (Sign in with Codex / Sign out of Codex, Sign in with Claude Code / Sign out of Claude Code, Save key / Remove saved key) and a key field is a --surface-input field that empties once saved. While a sign-in is in progress the fact reads so in --yellow, the URL the sign-in printed shows as selectable --mono text on --surface-input, and one field takes what the browser cannot return (for Codex the redirect URL, for Claude Code the code its page gives), with Finish sign-in and Cancel sign-in beside it in one row; the error a sign-in or sign-out ends with is a fact of the same grid in --red, as a status Claude Code fails to report is. Models is its own section: List models, then a two-column table (model, name) with --text-label uppercase headers. a modal per sign-in; a spinner without the URL; a saved key echoed back.
D-SET-6
+ Custom provider opens an empty form in the setup column, and a listed custom provider opens its filled form: Name, Kind (a choice between an alias of a built-in provider and an endpoint), for an alias the built-in provider it uses (a choice of Codex, Claude Agent, OpenAI, Anthropic or Gemini; the alias then runs with that provider's own sign-in or key, set up under that provider), and for an endpoint API (OpenAI Responses, OpenAI Chat Completions, Anthropic Messages or Gemini), Base URL and an optional Key, as a labelled grid of --surface-input fields; Save is the primary button, Remove provider sits beside it; a saved provider is listed by its name under the built-in ones. a wizard; the key shown after saving.
D-SET-7
Remote is one column of at most 640px: a section with Store URL, Share level (a choice) and Token fields in a labelled grid, Sign in to the store as the primary button and Check status beside it; then a Status section whose line reads in its tone (signed in, with the URL, the reviewer, the share level and what was pushed; signed out; or the error) with Push (dry run), Push results and, at the right, Sign out of the store; a push's result, a sign-in's notice or an error joins that one status line in its own tone. The token field empties once signed in. the token shown; a push without a dry run.
D-SET-8
Limits is one section: the sign-off idle grace in force as a fact in tabular figures (2 minutes, the default, unless changed; whole minutes read as minutes, else seconds), a seconds field of --control height, Save as the primary button, and a --ink-2 note that the new grace applies to the Runs started afterwards; a saved value replaces the fact. a slider; a unit other than seconds.
