Current: a branch's worktree as it is now

The Main area when a branch's Current is chosen: the header row with the scan's state, the tool strip and the Current graph lit by what verify would do. The bar and the Pane are as on the Monitor page; the Pane's Current entry sits in its pill.

  1. 1
    Scan stateIn the Main area's header row, after the view's name: while the scan runs, the checking icon and how many Artifacts are still being checked, as a count that falls (3 left); once it ends, the time it was scanned at; only a failure is said in words. Refresh at the row's end.
  2. 2
    Current graphDrawn at once from the declarations, every node first checking, then lit in place as the scan learns what verify would do.

Rules

D-CUR-1
The Current's scan state is the headline of the Main area's header row (D-MAIN-1), after Current · {project} {branch}: the scan's state in --ink-2 with tabular figures, said without a sentence: while it runs, the checking icon in --checking and n left, how many Artifacts are still being checked, a count that falls to none and is read aloud as Checking, n Artifacts left; once it ends, the time it was scanned at, HH:MM:SS, read aloud as Scanned at HH:MM:SS; only a failure is said in words, why it failed in --red. A small Refresh button sits at the row's end (Ctrl+R and F5 do the same); a refresh asked while a scan runs keeps that scan shown, the header still counting, and one more scan follows once it ends. a sentence for a scan that runs or ended well; a ratio that reads like a node's tally (3/24); a spinner without the count; the state in a banner; a second row for the scan's state; a key cap on Refresh.
D-CUR-2
The Current graph is drawn as a Run's (D-GRAPH-1, D-NODE-1 to D-NODE-4) under the same tool strip (D-GRAPH-4), with marks of its own (reused, would run, waiting, blocked, checking, each with its icon, named in Help, D-OVL-5); a node still being checked uses --checking and recolours in place. a different node shape for a Current; a redraw that moves the camera.
