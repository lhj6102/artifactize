# 기타 {#others}

보조 기능은 실제 머신에서 리뷰를 쓸 수 있게 해 줍니다.

- [상태, 캐시, 제한](state.md)에서는 Run과 증거가 어디에 있는지,
  캐시 확인과 제거, 동시 백엔드 용량, 저장된 Agent
  대화와 보존을 설명합니다. `artifactize doctor`는 제공자를 호출하거나 Run을 시작하지 않고
  로컬 준비 상태를 확인합니다. `models`는 쓸 수 있는 모델 ID를 나열하고,
  `prune`은 감사 기록은 보존하면서 제거할 수 있는 끝난 출력을 제거합니다.
- [운영체제](platforms.md)에서는 Linux, macOS, Windows에서의 이식 가능한 명령 선언, 실행 파일
  찾기, 경로, 애플리케이션 열기, 상태를 다룹니다.
- [보조 레퍼런스](reference.md)는 기능 가이드 뒤에 있는 자세한 스키마, 라이브러리 API,
  프로토콜, 제한으로 연결합니다.

명령 문법과 종료 코드는 [CLI](../../cli/index.md) 영역을 보세요.
