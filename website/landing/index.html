Build together on an Artifact Graph.

Artifactize brings human and agent work together and keeps your project consistent.

Artifactize는 사람과 에이전트의 작업을 하나로 모으고 프로젝트의 일관성을 지켜 줍니다.

Who is it for?

이런 분께 추천합니다

  • People who want to build together with others, reviewing efficiently and developing in modules.
  • 다른 사람과 함께 만들면서 효율적으로 리뷰하고 모듈 단위로 개발하고 싶은 사람.
  • People who want to trust changes made by AI agents without overseeing every step.
  • AI 에이전트가 일하는 과정을 일일이 지켜보지 않고도 에이전트가 바꾼 내용을 믿고 싶은 사람.
  • People who want code, documents, images, and running applications to stay consistent as the project grows.
  • 프로젝트가 커져도 코드, 문서, 이미지, 실행 중인 앱이 서로 어긋나지 않기를 바라는 사람.

01An idea

01아이디어

It starts with an idea.

아이디어에서 시작합니다.

A few notes on what to build. There is nothing to review yet.

무엇을 만들지 적은 메모 몇 줄입니다. 아직 리뷰할 것은 없습니다.

One idea, with no checks.

아이디어가 하나 있고, 아직 검사는 없습니다.

02Artifacts

02Artifact

The plan and specification become Artifacts.

계획과 명세가 Artifact가 됩니다.

Choose pieces to review separately. An AI checks whether the specification covers the plan.

따로 리뷰할 조각을 고르세요. AI는 명세에 계획 내용이 빠짐없이 반영됐는지 확인합니다.

The plan and specification become two Artifacts with one AI review.

계획과 명세가 두 Artifact가 되고, AI 리뷰 하나로 둘을 비교합니다.

03Checks

03검사

Code arrives, and checks connect the parts.

코드가 추가되고, 검사로 조각들을 연결합니다.

Compare pieces with each other. Alice approves the specification before work builds on it.

조각끼리 비교하세요. Alice는 명세를 바탕으로 작업을 시작하기 전에 명세를 승인합니다.

The code is compared with the specification; Alice signs off the specification.

코드가 명세에 맞는지 확인하고, Alice가 명세를 승인합니다.

04Tests and style

04테스트와 스타일

Tests and a style review check the code.

테스트와 스타일 리뷰로 코드를 검사합니다.

Tests check the code. AI checks its style against a guide approved by Alice.

테스트가 코드를 검사합니다. AI는 Alice가 승인한 가이드에 맞춰 코드의 스타일을 확인합니다.

Tests, an AI style review and Alice’s approval are three different checks.

테스트, AI 스타일 리뷰, Alice의 승인은 서로 다른 세 가지 검사입니다.

05Modules

05모듈

The code splits into modules.

코드가 모듈로 나뉩니다.

Give smaller code pieces their own checks so changes can be reviewed where they matter.

더 작은 코드 조각마다 검사를 붙이면, 변경의 영향을 받는 부분을 골라 리뷰할 수 있습니다.

The code splits into three parts, each with its own tests and review.

코드가 세 부분으로 나뉘고, 부분마다 따로 테스트하고 리뷰합니다.

06Beyond code

06코드 너머

A website and docs pages join the graph.

웹사이트와 문서 페이지도 Artifact Graph에 들어옵니다.

Check writing and design too: compare the guides with the app connections they describe.

글과 디자인도 검사하세요. 가이드에 설명된 앱 연결 방식이 실제 구현과 맞는지 확인합니다.

Documentation and website checks join, with Dana’s design approval.

문서와 웹사이트를 검사하고, Dana가 디자인을 승인하는 절차도 추가합니다.

07A change

07변경 하나

Change one module, and only what depends on it runs again.

모듈 하나를 바꾸면 그 모듈에 의존하는 것만 다시 실행됩니다.

Change those app connections. Only their checks and the checks that use them run again.

앱 연결을 바꿔 보세요. 그 연결을 확인하는 검사와 그 연결을 사용하는 부분의 검사만 다시 실행됩니다.

The changed app connections and their users are checked again; unrelated results still apply.

앱 연결 방식이 달라진 부분과 그 영향을 받는 부분만 다시 검사하고, 나머지 부분은 기존 검사 결과를 그대로 사용합니다.

08It keeps growing

08계속 성장합니다

New Artifacts and relations keep arriving.

새 Artifact와 연결이 계속 늘어납니다.

Add new work and connections without redesigning the project’s review process.

프로젝트의 리뷰 과정을 다시 설계하지 않고도 새 Artifact를 추가하고 Artifact끼리 연결할 수 있습니다.

A sync part, a brand guide and their checks join the project.

동기화 모듈과 브랜드 가이드를 프로젝트에 추가하고, 각각에 검사를 붙입니다.

09Work in parallel

09동시에 작업

Work on your own copy of the project.

각자 프로젝트 사본을 만들어 작업하세요.

A shared review store lets teammates reuse reviews earned in each other’s project copies.

공유 리뷰 저장소를 쓰면 팀원들이 저마다 작업하는 프로젝트 사본에서 받은 리뷰 결과를 서로 재사용할 수 있습니다.

Alice, Bob and Carol work separately and share their review results.

Alice, Bob, Carol이 따로 작업하고 리뷰 결과를 공유합니다.

10Merge and check

10합치고 검사

Bring changes together and check only what is new.

변경을 합치고 새로 생긴 것만 검사하세요.

Bring changes together. The team checks review the new combinations and read shared results without changing them.

변경을 하나로 합치세요. 팀 검사 단계에서는 새로 조합된 부분을 리뷰하고, 공유된 결과는 바꾸지 않고 읽기만 합니다.

The combined project reuses existing reviews and checks the new combinations.

프로젝트를 합친 뒤에는 기존 리뷰 결과를 재사용하고 새 조합만 검사합니다.

Artifactize's own Artifact Graph growing, recorded in the desktop app.

데스크톱 앱에서 Artifactize 프로젝트의 Artifact Graph가 성장하는 과정을 녹화했습니다.

Get started

시작하기

Try it in five minutes.

5분 만에 써 보세요.

Artifactize is open source under the Apache License 2.0. It runs on Linux, macOS and Windows; the quick start reviews an example project without an AI account or provider access key.

Artifactize는 Apache License 2.0으로 공개된 오픈 소스입니다. Linux, macOS, Windows에서 실행되며, 빠른 시작을 따라 하면 AI 계정이나 API 키 없이 예제 프로젝트를 리뷰할 수 있습니다.

Download for macOS macOS용 내려받기 Apple silicon and Intel · .dmg Apple 실리콘과 Intel · .dmg Get it for Windows Windows용 받기 Microsoft Store · x64 Download for Linux Linux용 내려받기 x86_64 · .deb

The app brings the artifactize command with it. On a Mac, open the app once to set up the Terminal command. On Ubuntu 22.04, Debian 12 or later, open the .deb with your software installer or run sudo apt install ./Artifactize-amd64.deb.

앱에 artifactize 명령이 함께 들어 있습니다. Mac에서는 앱을 한 번 열면 터미널에서 artifactize 명령을 쓸 수 있습니다. Ubuntu 22.04, Debian 12 이상에서는 소프트웨어 설치 프로그램으로 .deb를 열거나 sudo apt install ./Artifactize-amd64.deb를 실행하세요.

Or install from the command line

또는 명령줄에서 설치

# Linux (x86_64, aarch64): installs to ~/.local/bin, no sudo; on x86_64 also the desktop app# Linux (x86_64, aarch64): sudo 없이 ~/.local/bin에 설치, x86_64에서는 데스크톱 앱도 설치
$ curl -fsSL https://artifactize.dev/install.sh | sh
$ artifactize --version
# macOS (Apple silicon, Intel) with Homebrew# macOS (Apple 실리콘, Intel), Homebrew 사용
$ brew install lhj6102/tap/artifactize
$ artifactize --version
# Without Homebrew: installs to ~/.local/bin and the app to ~/Applications, no sudo# Homebrew 없이: sudo 없이 ~/.local/bin에, 앱은 ~/Applications에 설치
$ curl -fsSL https://artifactize.dev/install.sh | sh

With Homebrew, the app and the commands: brew install --cask lhj6102/tap/artifactize

Homebrew로 앱과 명령을 함께 설치하려면: brew install --cask lhj6102/tap/artifactize

# Windows x64 from the Microsoft Store, with the desktop app; then open a new terminal# Windows x64, Microsoft Store에서 데스크톱 앱과 함께 설치한 뒤 새 터미널을 여세요
PS> winget install 9PB6W4LL165D --source msstore
PS> artifactize --version
# Without the Store, in PowerShell with no administrator rights# Store 없이, 관리자 권한 없는 PowerShell에서
PS> irm https://artifactize.dev/install.ps1 | iex

The PowerShell download is not code-signed, so Smart App Control may block it; the Store version is signed by Microsoft.

PowerShell로 내려받는 파일은 코드 서명이 없어 Smart App Control이 막을 수 있습니다. Microsoft Store 버전은 Microsoft가 서명합니다.
