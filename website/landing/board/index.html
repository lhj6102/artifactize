How Artifactize is being built.

Artifactize splits a project into pieces that each carry their own checks, so people and AI agents can change it together and keep it consistent. Its own development runs on it, and this page follows that work live from the project’s GitHub repository.

A few words first: a commit is one saved version of the project, a branch is a separate line of work, and a pull request asks for a branch’s work to be added to another branch.

  • main holds the released versions.
  • dev is where finished work comes together. dev-master adds the waiting work, then runs every check on the result and fixes what fails until all pass; that commit is marked dev-green.
  • dev-worker agents each take one task on their own branch, starting from dev-green, and ask to join dev once their checks pass.
  • dev-master brings that work into dev and fixes what breaks. The project’s owner decides each release.
